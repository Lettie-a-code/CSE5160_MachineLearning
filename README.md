# CSE5160_MachineLearning

## Comparison of Machine Learning Algorithms for Diabetes Prediction

### Project title and project type:  

"Comparison of Machine Learning Algorithms for Diabetes Prediction"

### Problem statement: 

The objective of this study is to compare the performance of several supervised machine learning algorithms for predicting diabetes using demographic and medical data. The study will evaluate and compare four classification algorithms:
- Logistic Regression
- Decision Tree
- Random Forest
- Gaussian Naive Bayes

### Research Question: 
Which machine learning algorithm provides the most effective diabetes prediction performance on the selected dataset?

### Experimental Design:

Each algorithm will be trained and tested using the same dataset and data preparation process to ensure a fair comparison. The performance of each model will be evaluated using several classification metrics.

### Evaluation Metrics:
- Accuracy: Measures the overall percentage of correct predictions.
- Precision: Measures the proportion of positive diabetes predictions that are correct.
- Recall: Measures the proportion of actual diabetes cases correctly identified.
- F1-Score: Provides a balanced measure of precision and recall.
- Confusion Matrix: Visualizes the number of true positives, true negatives, false positives, and false negatives.

### Expected Outcome:
The experiment will identify which supervised learning algorithm achieves the best predictive performance for diabetes detection and provide insight into the strengths and weaknesses of different classification approaches when applied to healthcare data.
